## 先搞清楚：东京节点有两条完全不同的线路

雨云东京机房的"日本一区"和"日本二区"不是两个机房的区别，主要差在线路上。

**极速三网**针对国内访问做优化。去程电信走 163 骨干网、联通走 AS4837、移动走 CMI，回程电信走 CN2 优化线路。第三方测评记录到的全国平均延迟大致是：电信约 90ms、联通约 55ms、移动约 71ms，港澳台地区约 41ms。适合网站、API、后台这类"国内用户要经常访问"的场景。

**软银大带宽**走日本软银线路，峰值带宽给得更大，从 50Mbps 一路到 300Mbps，代价是延迟和稳定性不如前者。

两条线路各自又分"大带宽限流量型"和"小带宽不限流量型"。同一台机器，你选了不限流量，上传带宽就会明显缩水——比如 2核4G 那档，限流量款给 100Mbps，不限流量款上传只有 20Mbps，价格相同。

## 有限流量还是无限流量，算一笔账

先说清楚"有限流量"的计费规则，这是最容易踩坑的地方。

雨云的流量计费是**双向的**，上行和下行都算。买 30GB 的档位，实际能跑的量比想象中少。不过有两个缓冲机制比较友好：当月用不完的流量不会清零，可以叠加到下个月；流量跑完之后不会直接停机，而是限速——极速三网降到 1Mbps，软银线降到 5Mbps，限速状态下服务器还能连，只是慢。

想恢复速度就得买流量包。极速三网的加量价格是 20G / 20 元、100G / 100 元、200G / 180 元；软银线是 500G / 50 元、1TB / 80 元。单看每 GB 单价，大额流量包反而更便宜，所以如果你习惯"先买小档、不够再加"，得知道加量的边际成本并不低——30GB 档 33 元，再加 200GB 要 180 元，已经远远超过直接买大档的价格。

判断逻辑可以很直接：

- 建站、做 API、跑轻量爬虫这类**流量可预期**的用途，选有限流量。你换来的是高得多的带宽，33 元档就有 20Mbps 上行 / 40Mbps 下行。
- 下载中转、图床、监控回传、开发测试环境这类**流量不可预期或者持续跑量**的用途，选无限流量。带宽窄，但不用每天盯流量表。
- 拿不准的时候，先买最低档试一个月。雨云支持 1 元试用和 7 天无理由退款（同一账号限 3 次），试错成本很低。

## 几个容易被忽略的细节

**IP 不是原生 IP。** 多个第三方测评都提到这一点，IP 归属显示在东京（上游为 NetLab），但属于广播 IP。这意味着访问日本本地服务没问题，想解锁日区流媒体则没有保证。如果你的需求是"用日本 IP 看日区内容"，这是要先确认的点，别下单之后才发现不对。

**IP 要另外算钱。** 默认自带 1 个普通 IPv4（按 5 元/月计价，已含在套餐里），需要额外 IP 就按 5 元/个加。另有 300G 以上防护的日本高防 IP 可选，30 元/月。对普通建站用户来说，高防 IP 属于用不上就不用买的东西；做游戏服、易被攻击的业务才值得考虑。

**海外节点免备案。** 东京、香港、洛杉矶都不需要备案，国内节点（宿迁、宁波、十堰、深圳）用作带域名的网站才需要先备案。

## 优惠怎么叠，能便宜到多少

雨云的折扣结构分三层，叠不叠得上，差别不小。

第一层是**新用户首月 5 折**。通过专属优惠链接注册账号并绑定微信之后，系统会自动发一张首月 5 折券，不用手动输码。这是新账号能拿到的最大力度折扣，适合先买一个月验证线路和性能。

第二层是**长期付费折扣**。官方对季付、半年付、年付都有折扣，年付 7 折是最常被提到的档位。这层折扣可以和优惠券叠加使用，所以"首月 5 折试水 + 确认没问题后转年付 7 折"是很多人实际采用的路径。

第三层是**积分商城兑换的优惠券**。所有用户都能在积分中心兑换，单张最高 20 元，商城每天晚 8 点刷新。积分来源有三条：消费返积分（比例在 10%–20% 之间）、日常任务（每日签到约 500 积分，绑定微信、邮箱等新人任务一次性可拿到数千积分）、以及推广邀请。换算关系是 2000 积分 = 1 元，可以提现也可以换成券。

组合起来的真实成本：以极速三网 53 元/月那档为例，行价 53 元，年付 7 折后 37.1 元/月；如果再叠加一张 8 折券，实际单价大约 29.7 元/月，一年下来省的不是零头。但要说清楚——券有有效期和适用范围，能叠到哪一步取决于你手上具体是哪张券，宣传口径里的"5.6 折""3 折"这类数字都建立在特定券组合上，别当成官方统一价。

至于续费，首月券只作用于首月，长期使用主要靠年付折扣加积分券维持。这也是为什么建议首月先按折扣试，觉得稳定再签长约。

## 什么情况适合，什么情况别选

适合的情况比较明确：预算敏感但需要一条国内访问不绕路的日本线路。个人博客、小型企业站、跨境业务的海外后台、爬虫和测试环境、轻量 API 服务，这类需求用 33–53 元档的极速三网就够，延迟数据也撑得住。

不太适合的也很明确：需要日区原生 IP 解锁流媒体；需要大带宽同时又不想管流量（这两件事在同类产品里本来就不容易同时满足）；需要 GPU 算力或者几百 G 的大流量高防——雨云有裸金属、GPU 服务器和国内高防节点，但那是另一条产品线，用东京节点解决不了。

顺带说一句，如果东京不是硬需求，雨云的区域清单里还有中国香港（三网直连和软银 BGP 两套）、洛杉矶（国际大带宽和精品网两套）、以及宿迁、宁波、十堰、深圳这些国内节点。香港三区的延迟比东京更低，价格结构相近，做免备案站点经常比东京更划算。

不需要。海外节点都免备案，只有国内节点用作带域名的网站时才需要先备案。

**流量用完了会停机吗？**
不会。极速三网会限速到 1Mbps，软银线限速到 5Mbps，服务器照常在线，可以买流量包恢复速度。当月没用完的流量还能结转下个月。

可以。Linux、Windows 镜像都有，宝塔、1Panel、Docker、MCSManager 这些环境可以一键装。MacOS 东京节点不支持。
